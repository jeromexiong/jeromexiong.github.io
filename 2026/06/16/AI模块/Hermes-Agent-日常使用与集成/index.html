Hermes Agent 日常使用与集成

Hermes Agent 不仅是 CLI 工具，还支持网关模式、定时任务、多平台消息推送等生产级能力。

网关模式

网关模式让 Hermes 作为后台常驻服务运行，通过微信、Telegram、Discord 等平台交互。

启动网关

1hermes gateway

WeChat 集成

通过 WeChat 网关，可以在微信中直接与 Hermes 对话：

  • 发送消息 → Hermes 处理 → 返回结果
  • 自动识别上下文，追踪对话线程
  • 支持文件、图片等多模态输入

配置方式（config.yaml）：

1# 网关相关配置
2gateway:
3  strict: false
4  trust_recent_files: true
5  trust_recent_files_seconds: 600

消息格式

内容类型 说明
文本 直接对话
图片 自动 OCR/视觉分析
文件 代码审查、文档处理
URL 网页摘要、内容分析

定时任务 (Cron)

Hermes 内置定时任务调度器，支持：

1# 创建定时任务
2cronjob(action='create', schedule='0 9 * * *', prompt='每天早上9点推送新闻简报')
3
4# 列出任务
5cronjob(action='list')
6
7# 管理任务
8cronjob(action='pause', job_id='xxx')
9cronjob(action='remove', job_id='xxx')

支持的时间格式：

格式 说明
30m 每30分钟执行
every 2h 每2小时执行
0 9 * * * 每天9点（cron 格式）
2026-06-01T09:00:00 一次性的定时任务

定时任务可以附带技能，也可以运行自定义脚本（Watchdog 模式）。

MCP 工具

Hermes 内置原生 MCP 客户端，连接 MCP 服务器即可动态注册工具。

已配置的 MCP 工具

1. CodeGraph — 代码分析

1mcp_servers:
2  codegraph:
3    command: codegraph
4    args: [serve, --mcp]

用于：代码结构分析、调用链路追踪、影响范围分析、搜索符号。

2. Midscene Web — 浏览器自动化

1mcp_servers:
2  midscene-web:
3    command: npx
4    args: ['@midscene/web-bridge-mcp']

用于：网页操作、截图验证、表单填写、功能测试。

日常使用场景

场景一：代码审查

1请求：帮我审查这个 PR 的代码
2→ 自动加载 github-code-review 技能
3→ 读取 diff → 分析代码质量 → 生成审查意见

场景二：文章写作

1请求：写一篇关于 Swift Concurrency 的文章
2→ 自动匹配写作技能
3→ 生成初稿 → 润色 → 发布到博客

场景三：服务器运维

1请求：检查服务器状态
2→ 自动连接服务器 → 执行诊断命令 → 返回报告

场景四：定时新闻简报

设定每天早上自动推送技术资讯到微信：

1cronjob(action='create', schedule='0 8 * * *', 
2        prompt='搜集今天的技术热点，生成中文摘要推送到微信')

小贴士

💡 记忆系统 — Hermes 会记住你的偏好和项目配置，无需重复说明

⚠️ 安全性 — 敏感命令需要手动确认（删除文件、重启服务等）

🔄 持续更新 — hermes update 拉取最新版本（当前 v0.15.1，落后 1924 commits 时有更新提示）
