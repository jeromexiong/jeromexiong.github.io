Hermes Agent 的核心能力来源于**技能（Skills）**系统。每个技能是一个 markdown 文件，定义了特定场景下的行为、工作流和注意事项。

技能系统概览

技能文件存储在 ~/.hermes/skills/ 下，按类别组织：

1skills/
2├── academic/           # 学术写作
3├── apple/              # Apple 生态（iMessage, 提醒事项）
4├── autonomous-ai-agents/  # AI 智能体
5│   ├── hermes-agent/   # Hermes 自身配置
6│   ├── claude-code/    # Claude Code 集成
7│   ├── codex/          # OpenAI Codex
8│   ├── karpathy-guidelines/  # Karpathy 编码准则
9│   └── ...
10├── creative/           # 创意内容（ASCII 艺术、漫画、P5.js）
11├── engineering/        # 工程开发
12├── marketing/          # 营销推广
13├── devops/             # DevOps 运维
14├── mcp/                # MCP 协议
15│   ├── native-mcp/     # 原生 MCP 客户端
16│   └── playwright-cli/ # 浏览器自动化（Playwright）
17├── github/             # GitHub 工作流
18├── testing/            # 软件测试
19└── ...

总计 320+ 技能，覆盖 55 个类别。

加载技能

技能会自动匹配任务场景，也可以手动加载：

1# 在 Hermes 中手动加载
2/skill <技能名>
3
4# 在提示词中引用
5请加载 karpathy-guidelines 技能后回答

1. Karpathy Guidelines

来源：multica-ai/andrej-karpathy-skills（clawhub 有中文版，本文档安装的是 clawhub/karpathy-guidelines）

著名的 AI 编码行为准则，包含 4 条核心原则：

  1. Think Before Coding — 显式陈述假设，不默默选择
  2. Simplicity First — 只写最少代码，不过度抽象
  3. Surgical Changes — 只改必须改的行，不顺手重构
  4. Goal-Driven Execution — 先定义成功标准再执行

安装方式：

1hermes skills install clawhub/karpathy-guidelines

安装后写入 ~/.agents/skills/karpathy-guidelines/，通过软连接同步到 Hermes 与 Claude Code。

2. Claude Code / Codex 集成

claude-code 编码委托 用 Claude Code CLI 处理复杂编码任务
codex 编码委托 用 OpenAI Codex CLI 处理编码任务
opencode 编码委托 用 OpenCode CLI 处理编码任务

3. 浏览器自动化 (Playwright MCP)

基于 MCP 协议的浏览器自动化工具，用 Accessibility Tree 操作页面，无 VLM 推理成本：

1# ~/.agents/mcp/playwright.yaml（全局配置，Hermes / Claude Code 共用）
2name: playwright
3command: npx
4args:
5  - '@playwright/mcp@latest'

💡 变更记录：2026-08 起全局 MCP 从 midscene-web（截图 + VLM 推理）替换为 playwright（Accessibility Tree）。Playwright 确定性更高、Token 消耗远低于 Midscene 的 VLM 模式，适合 CI/CD 和 Coding Agent 场景。

用于：网页测试、表单填写、数据抓取、功能验证。也可用 @playwright/cli（CLI + Skills 方案，Token 效率更高）。

4. Agency Agents — Claude Code 人格库

来源：msitarzewski/agency-agents（⭐ 137k+）

232 个预定义的 AI Agent 人格，安装到 ~/.claude/agents/（软连接指向 ~/.agents/agents/），在 Claude Code 中用 @agent-name 调用，Codex 通过 ~/.codex/skills/agents 同样可以访问：

分类 Agent 数 示例
Marketing 36 @seo-specialist, @content-creator, @growth-hacker
Engineering 33 @frontend-developer, @backend-architect, @code-reviewer
Specialized 13 @mcp-builder, @prompt-engineer, @workflow-architect
GIS 13 空间数据、地图可视化
Sales 11 @deal-strategist, @sales-engineer
Security 10 安全审计、渗透测试
Design 9 @ui-designer, @ux-architect, @brand-guardian
Testing 8 测试自动化、质量保障
Product 5 @product-manager, @sprint-prioritizer
Finance 5 @financial-analyst, @tax-strategist

安装方式：

1git clone --depth 1 https://github.com/msitarzewski/agency-agents.git /tmp/agency-agents
2cd /tmp/agency-agents
3bash scripts/install.sh --tool claude-code --no-interactive
4rm -rf /tmp/agency-agents

5. UI/UX Pro Max — 设计智能

来源：nextlevelbuilder/ui-ux-pro-max-skill（⭐ 112k+）

全面的 UI/UX 设计智能技能，内置可搜索的设计数据库，覆盖 Web 与移动端：

资源 数量
设计风格 50+（glassmorphism、minimalism、brutalism、bento grid…）
配色方案 161 套
字体搭配 57 组
产品类型 161 种（含推理规则）
UX 准则 99 条
图表类型 25 种
技术栈 10 种（React、Next.js、Vue、Svelte、SwiftUI、Flutter、Tailwind…）

核心用法（Python CLI 搜索，10 大规则域按优先级排列：Accessibility → Touch → Performance → Style → Layout → Typography → Animation → Forms → Navigation → Charts）：

1# 生成完整设计系统（推荐起点）
2python3 skills/ui-ux-pro-max/scripts/search.py "beauty spa wellness service" --design-system -p "Serenity Spa"
3
4# 按领域深挖
5python3 skills/ui-ux-pro-max/scripts/search.py "glassmorphism dark" --domain style
6python3 skills/ui-ux-pro-max/scripts/search.py "fintech crypto" --domain color
7
8# 按技术栈获取实现规范
9python3 skills/ui-ux-pro-max/scripts/search.py "list performance navigation" --stack nextjs

特色：--design-system 一键输出风格/配色/字体/反模式；--persist 保存 Master + 页面级覆盖（design-system/MASTER.md）；可集成 shadcn/ui MCP 组件搜索。

6. Reasonix — DeepSeek 原生编码框架

Reasonix 是基于 DeepSeek 原生 API 的编码智能体框架，特点和优势：

特性 说明
版本 v0.50.1
模型 deepseek-v4-flash / deepseek-v4-pro
缓存 主动缓存优化（前缀共享 + 会话持久化）
成本 比 Claude Code 节省约 97%

命令速查：

命令 用途
reasonix run "任务" 非交互模式，单次任务
reasonix code 交互模式，带缓存/成本实时面板
reasonix stats 查看缓存命中率和成本统计
reasonix doctor 检查环境配置

与 Claude Code 的成本对比：

场景 Claude Code → DeepSeek Reasonix (原生)
单次调用 ~$0.009 ~$0.00027
缓存策略 服务端决定 主动前缀共享 + 会话持久化
交互模式 claude reasonix code

8. MCP（Model Context Protocol）

原生 MCP 客户端支持，可连接任意 MCP 服务器动态注册工具。当前配置了：

  • playwright — 浏览器自动化（Accessibility Tree，2026-08 起替换 midscene-web）
  • codegraph — 代码图谱分析

安装三方技能

从 GitHub 仓库安装技能：

1# 克隆仓库到 skills 目录
2git clone <repo-url> ~/.hermes/skills/<category>/<skill-name>

安装后重启 Hermes 即可使用。也可以使用 hermes install 命令（如果支持）。

插件系统
