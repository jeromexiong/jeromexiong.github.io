Xcode & Android Studio 快捷键

熟练掌握 IDE 快捷键能够显著提升开发效率。本文整理了 Xcode 和 Android Studio 中最常用的快捷键操作，便于日常编码时快速查阅。

XCode快捷键

1⌥ —> option | alt 
2⇧ —> shift 
3⌃ —> control 
4⌘ —> command 
5⎋ —> esc 
6↑↓←→
1格式化代码：Structure Re-indent     ⌃i
2向右缩进：Structure shift Right     ⌘]
3向左缩进：Structure shift Left     ⌘[
4整行向上移动：Structure Move Line Up     ⌥⌘[
5整行向下移动：Structure Move Line Down     ⌥⌘]
6注释代码：Structure Comment Selection     ⌘/
7代码提示：Show Completions     ⌥⌘/
8删除光标至行首的内容     ⌘ delete
9删除光标至本段末的内容     ⌃ K
10新建文件：⌘ N
11新建空文件：⌘⌥N
1上次／下次光标位置：command+control+arrow left／right
2折叠／展开代码：command+option+arrow left／right
3
4快速帮助：在类或者方法名上执行Option + Left-click操作
5跳至父类或方法：command＋Left-click
6
7跳转栏和快速打开搜索输入快捷键：Command + Shift + O
8快速跳转：Command + Shift + J（跳至当前打开文件位置）
9
10文档和参考: Command + Shift + 0 (Zero)
11'Show Related Items'弹出菜单：CTRL + 1
12
13搜索导航器(Find Navigator，也就是搜索):Command+Shift+F
14运行app: Command + R
15清除工程: Command + Shift + K
16构建应用程序: Command + B

隐藏所有窗口并显示桌面 F11 http://www.360doc.com/content/12/0521/09/6541311_212458595.shtml http://www.cocoachina.com/ios/20141224/10752.html

xib 快捷键

1option + ：同时打开两个文件
2alt 左键 ：控件连线
3按住 shift ：属性多选
4option command = ：更新约束
5双击约束：调整约束具体设置

Android Studio 快捷键

1/**
2 * Mac OS X 10.5+
3 * command U(或 鼠标点击) 查看父类方法
4 * shift+command+上下方向键：Move Line Up/Move Line Down
5 * alt+command+L：格式化代码
6 * alt+enter：优化import（去掉无用的import）
7 * command X(delete) 剪切(删除)
8 * 大小写转换：⌘⇧U
9 * 重命名：⇧F6
10 * command+D: 复制整行到下一行
11 * Extract Method 抽取成方法：⌘⌥M
12 * Extract Field 抽取为成员属性：⌘⌥F
13 * 选择能重写(override)或实现(implement)的方法 ：⌃o
14 * 如eclipse中的⌘1的action(即win-eclipse上的ctrl+1)：⌥⏎    quick fix
15 * CMD + ALT + V   相当于Eclipse的Ctrl + 2 ,L  自动生成变量
16 * CMD + ALT + F   抽取成成员变量
17 * control+J 查看该方法的api
18 * CTRL + T    调出Refactor选项框，可以抽取方法、成员变量等
19 * control+alter+/: Class name completion 代码提示
20 * control+H: 查看类结构图
21 * command+, :调出preferences
22 * alter+command+O:查找工程内的文件或方法或字段
23 * -----------
24 * 快捷方法
25 * logt: private static final String TAG = "MainActivity";
26 */
27Mac版
28－－－－－－
29代码提示：     Class Name Completion     ⌃⌥／
30格式化代码：  Reformat Code     ⌥⌘L
31快速打开光标处的类或者方法：Declaration     ⌘B
32查看Javadoc：Quick Documentation     ⌃J
33抽取成员变量｜常量：Extract Field｜Constant     ⌥⌘F ｜⌥⌘C
34重命名：     ⇧F6
35快捷键模版：Insert Live Template     ⌘J
1Ctrl+G / Ctrl+Alt+Shift+G：查询变量或者函数或者类在哪里被使用或被调用，后者是前者的复杂表现，可以选择查询范围等。
2Alt+H：查找功能，全局查找
3F4：查看类继承关系
4F2：查看文档说明（函数使用说明）
5Ctrl+E：查看最近打开过的文件
6Ctrl+Shift+E：查看最近编辑过的文件
7double Shift：全局查找，这个查看和Alt+H稍稍有些不同，这个是全局文件查找，到文件名称层面。
8Ctrl+Shift+R：快速定位到你所想打开的文件。
9Alt+↑：光标所在位置那行代码往上移动
10Alt+↓：光标所在位置那行代码往下移动
11Ctrl+D：删除光标所在位置那行代码
12Ctrl+X：剪切光标所在位置那行代码
13Alt+Shift+↓/Ctrl+C：复制光标所在行代码到下一行
14Ctrl+O:快捷查找当前类中的函数，变量
15Ctrl+Shift+R：修改名称
16Alt+Enter：导入包
17Alt+←：后退，定位到上个查看或者编辑的地方
18Alt+→：往前定位，比如你定位到上个点后，想回去，就可以用这个快捷键
19Ctrl+/：当行注释，反注释再按一次即可
20Ctrl+Shift+/：模块注释，反注释再按一次即可,注意这边的"/"不能用小键盘的
21Ctrl+Shift+小键盘/：折叠代码（Ctrl+Shift+小键盘*这个不灵了，今天没空了，后面会针对这个问题做解决，并更新上来），当然笔记本没小键盘，你可以自己改快捷键
22Ctrl+Alt+S：打开settings界面
23Ctrl+Alt+Shift+S：打开Project Structure界面
24Alt+Shift+X：运行（Run）
25Alt+Shift+D：调试运行（Debug）
26Ctrl+F9：编译工程
27Ctrl+Shift+K：push文件到Server（git）
28Debug类快捷键
29F5：但不调试进入函数内部。
30F6：但不调试不进入函数内部。
31F7：由函数内部返回调用处。
32F8：执行到下一个断点，没断点则执行完成。
Action Mac OSX Win/Linux

格式化代码 Cmd + Option + L Ctrl + Alt + L
清除无效包引 用 Option + Control + O Alt + Ctrl + O
查找 Cmd + F Ctrl + F
查找+替换 Cmd + R Ctrl + R
上下移动代码 Option + Shift + Up/Down Alt + Shift + Up/Down
删除行 Cmd + Delete Ctrl + Y
扩大缩小选中范围 Option + Up/Down Ctrl + W/Ctrl + Shift + W
快捷生成结构 体 Cmd + Option + T Ctrl + Alt + T
快捷覆写方法 Ctrl + O Ctrl + O
快捷定位到行首/尾 Cmd + Left/Right Ctrl + Left/Right
折叠展开代码块 Cmd + Plus,Minus Ctrl + Plus/Minus
折叠展开全部代码块 Cmd + Shift + Plus,Minus Ctrl + Shift + Plus,Minus
文件方法结 Cmd + F12 Ctrl + F12
查找调用的位置 Ctrl + Option + H Ctrl + Alt + H
