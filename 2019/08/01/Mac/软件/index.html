Mac 常见问题

刷新DNS

1sudo dscacheutil -flushcache
2sudo killall -HUP mDNSResponder

xxx.app已损坏,打不开.你应该将它移到废纸篓-已解决

  1. 系统偏好设置... -> 安全性与隐私-->修改为任何来源

  2. serria里面没有"任何来源"这一项，需要打开终端执行sudo spctl --master-disable，这个时候再去系统偏好设置... -> 安全性与隐私 是不是发现有了"任何来源"这一项

    允许任何来源的软件

    sudo spctl --master-disable

    关闭

    sudo spctl --master-enable

已经勾选"允许任何来源"，为啥还是提示"文件已损坏"

打开终端，在终端中粘贴下面命令：【sudo xattr -r -d com.apple.quarantine 】 ,然后输入个空格，再将应用程序目录中的软件拖拽到命令后面，按回车后输入密码执行。 比如：Sketch的命令是 sudo xattr -r -d com.apple.quarantine /Applications/Sketch.app 亲测可行

MAC查看端口占用情况

  • lsof -i tcp:port （port替换成端口号，比如6379）可以查看该端口被什么程序占用
  • kill port 关闭端口

显示finder的所有文件，包括隐藏文件

defaults write com.apple.Finder AppleShowAllFiles true 然后按住option+右击finder，重启finder Command shift . 隐藏显示隐藏文件

Q:Can't chown /usr/local in High Sierra

A:sudo chown -R $(whoami) $(brew --prefix)/*
