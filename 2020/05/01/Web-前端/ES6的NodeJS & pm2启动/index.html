ES6的NodeJS & pm2启动

Jerome Xiong
 2020-05-01 18:002020-05-01 18:00创建 
  • Web
 1.6k 字 6 分钟

本文详细讲解如何从零搭建支持ES6语法的Node.js项目，涵盖Babel转码配置、PM2集群部署以及forever进程管理，帮助你将Node.js应用高效部署到生产环境。

创建支持ES6的NodeJS项目

  1. 新建一个空的文件夹，在根目录执行：npm init -y。会生成一个package.json文件

  2. 安装依赖

安装express： npm install --save express

安装babel转码编译：npm install --save-dev babel-register babel-preset-env

  1. 在文件根目录创建.babelrc文件，内容如下：
1{
2	"presets": [
3		["env", {
4			"targets": {//只转码当前不支持语法
5			"node": "current"
6			}
7		}]
8	]
9}
  1. 新建一个src文件夹，并在文件内新建 main.js内容如下：
1import Express from 'express'
2
3let app = Express()
4
5app.get('/', (req, res) => {
6  res.send('hello world')
7})
8
9app.listen(8080, () => console.log('server is running at http://localhost:8080'))

这样还是不能直接运行的，必须要经过转码后才可执行！新建index.js文件作为主入口：

1require('babel-register');
2require('./src/main.js')

编写代码后执行：

node index.js

发布时

因为babel-register是实时转码的，所以实际发布时，应该先转码整个app文件

安装依赖 npm install -g babel-cli

转码 babel app -d dist

这次只需要启动dist目录下的app.js即可

使用forever, pm2 让Nodejs持久运行

最简单粗暴的方法是使用Linux本身后台执行的特性

使用&符号后台执行，并利用nohup命令实现进程禁止挂起

nohup node app.js &

使用PM2运行nodeJS

以下是针对 Egg.js 应用结合 PM2 的配置文件示例，支持集群模式、环境变量配置和日志管理：

1// ecosystem.config.js
2module.exports = {
3  apps: [{
4    name: 'egg-app', // 应用名称
5    script: 'npm', // 使用 Egg.js 官方脚本
6    args: 'run start', // 启动命令
7    instances: 'max', // 使用所有 CPU 核心
8    exec_mode: 'cluster', // 集群模式
9    watch: false, // 生产环境关闭监听
10    autorestart: true, // 异常退出时自动重启
11    max_memory_restart: '1G', // 内存超过 1G 自动重启
12    // 环境变量配置
13    env: {
14      NODE_ENV: 'development',
15      PORT: 7001
16    },
17    env_production: {
18      NODE_ENV: 'production',
19      PORT: 7001
20    },
21    // 日志配置
22    log_file: './logs/combined.log',
23    out_file: './logs/out.log', // 标准输出日志
24    error_file: './logs/error.log', // 错误日志
25    log_date_format: 'YYYY-MM-DD HH:mm:ss Z', // 日志时间格式
26    // 高级配置
27    instance_var: 'INSTANCE_ID',
28    min_uptime: '10s',
29    max_restarts: 10,
30    // Egg.js 特定配置
31    node_args: '--harmony',
32    cwd: './' // 应用根目录
33  }]
34};

配套的 Egg.js 配置文件 (config.default.js)：

1// config/config.default.js
2module.exports = appInfo => ({
3  cluster: {
4    listen: {
5      path: '',
6      port: process.env.PORT || 7001, // 优先使用环境变量端口
7      hostname: '0.0.0.0' // 允许外部访问
8    }
9  },
10  // 自定义日志路径（与 PM2 配置对应）
11  logger: {
12    dir: './logs',
13    level: 'INFO'
14  }
15});

使用说明：

  1. ​启动应用​：

    1# 开发环境
2pm2 start ecosystem.config.js
3
4# 生产环境
5pm2 start ecosystem.config.js --env production

  2. ​常用 PM2 命令​：

    1pm2 status egg-app          # 查看状态
2pm2 reload egg-app          # 平滑重启（零停机）
3pm2 logs egg-app --lines 100 # 查看日志
4pm2 save                    # 保存当前进程列表
5pm2 startup                # 设置开机自启

关键配置说明：

  • ​集群模式​：通过 instances: 'max'充分利用多核 CPU
  • ​平滑重启​：使用 pm2 reload避免服务中断
  • ​日志管理​：分离输出/错误日志便于问题排查
  • ​环境隔离​：通过 env配置区分不同环境变量

此配置已优化生产环境部署，支持高性能集群运行和完整的运维监控需求。

pm2部署项目

使用ssh-agent代理设置ssh通信. ssh-keygen -C "comment" 注意：不要修改文件名称，直接回车即可

⚠️ pm2 内存中只存在一个进程，必须执行pm2 update 刷新内存. ps -ef |grep pm2 查看进程状态。 最好不要运行两个pm2，会相互挤占进程，导致运行错误。 Easy Deploy with SSH

SSH无密码（密钥验证）登录的配置

  • 配置主机A免密登录到主机B（方法一）
    1. 在主机A生产密钥对: ssh-keygen -t rsa， 会在.ssh目录下产生密钥文件
    2. 拷贝主机A的公钥到主机B: scp id\_rsa.pub
    3. 将主机A的公钥加到主机B的授权列表.ssh/authorized\_keys（若不存在，手动创建）: cat id\_rsa.pub >> authorized\_keys
    4. 授权列表authorized\_keys的权限必须是600，chmod 600 authorized\_keys 　
  • （方法二）
    1. 进入到我的home目录 cd \~/.ssh ssh-keygen -t rsa （四个回车） 执行完这个命令后，会生成两个文件id\_rsa（私钥）、id\_rsa.pub（公钥）
    2. 将公钥拷贝到要免登陆的机器上： ssh-copy-id localhost

使用forever让node.js持久运行

1npm install forever -g   #安装
2forever start app.js  #启动应用
3forever stop app.js  #关闭应用
4forever restartall  #重启所有应用
5
6#输出日志和错误
7forever start -l forever.log -o out.log -e err.log app.js   
8
9# 指定forever信息输出文件，当然，默认它会放到~/.forever/forever.log
10forever start -l forever.log app.js  
11
12# 指定app.js中的日志信息和错误日志输出文件，  
13# -o 就是console.log输出的信息，-e 就是console.error输出的信息
14forever start -o out.log -e err.log app.js 
15
16# 追加日志，forever默认是不能覆盖上次的启动日志，  
17# 所以如果第二次启动不加-a，则会不让运行  
18forever start -l forever.log -a app.js
19
20# 监听当前文件夹下的所有文件改动（不太建议这样）  
21forever start -w app.js  
22
23# 显示所有运行的服务 
24forever list  
25
26######停止操作
27
28# 停止所有运行的node App  
29forever stopall  
30  
31# 停止其中一个node App  
32forever stop app.js  
33
34# 当然还可以这样  
35# forever list 找到对应的id，然后：  
36forever stop [id]
37
38# 开发环境下  
39NODE_ENV=development forever start -l forever.log -e err.log -a app.js  
40# 线上环境下  
41NODE_ENV=production forever start -l ~/.forever/forever.log -e ~/.forever/err.log -w -a app.js
42#上面加上NODE_ENV为了让app.js辨认当前是什么环境用的

HuiLive shell

1#!/bin/sh
2# init file for AnyRTCLive web server
3# by Ming.Niu
4#
5# chkconfig: - 90 90
6# description: DYNC AnyRTCLive Web Server
7
8. /etc/init.d/functions
9
10#PATH=/usr/local/anyrtc/service/anyrtc_nodejs_server/:$PATH
11
12RUNASUSER=root
13UGID=$(getent passwd $RUNASUSER | cut -f 3,4 -d:) || true
14
15prog="HuiLiveWebServer"
16
17daemonStr="/usr/local/anyrtc/HuiLiveWebServer/bin/HuiLive"
18logPath="/var/log/node-HuiLive/"
19params="-a -l ${logPath}forever.log -o ${logPath}console.log -e ${logPath}error.log"
20
21[[ -d ${logPath} ]] || mkdir ${logPath}
22#==============================================================================
23start()
24{
25    echo -n $"Starting HuiLive Web Service: "
26    if [ -z "$UGID" ]; then
27        echo "User \"$RUNASUSER\" does not exist!"
28            failure
29    else
30        pid="$(__pids_pidof "$prog")"
31        if [ -z "$pid" ]; then
32            su - $RUNASUSER -c "forever ${params} start ${daemonStr}"
33            echo "Log files in ${logPath}"
34	    sleep 2
35            ps -ef|grep HuiLiveWebServer |grep -v grep
36            if [ $? -ne 0 ]
37                then
38                failure
39            else
40                success
41            fi
42        else
43             echo "HuiLive Web Service (pid $pid) is still running..."
44             failure
45        fi   
46    fi  
47     echo
48}
49
50case "$1" in
51start)
52    start
53    ;;
54stop)
55    su - $RUNASUSER -c "forever stop ${daemonStr}"
56    ;;
57restart)
58    su - $RUNASUSER -c "forever stop ${daemonStr}"
59    start
60    ;;
61status)
62    su - $RUNASUSER -c "forever list &"
63    ;;
64*)
65    echo "Usage: $0 (start|stop|restart|status)"
66esac
